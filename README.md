# NEGUSBRINE — Personal Website

A responsive single-page personal website built with HTML, CSS and JavaScript.

## Preview locally
Open `index.html` in a modern browser. An internet connection is used for Google Fonts. The rain ambience is generated in-browser and starts only when the visitor presses Play.

## Publish with GitHub Pages
1. Create a GitHub repository named `negusbrine.github.io` (for a personal site).
2. Upload `index.html` and the `assets` folder to the repository root.
3. Open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site.

## Notes
- The visitor counter is local to the visitor's browser/device. A shared global visitor count needs a third-party counter service or backend.
- Discord is shown as a copyable username because no invite/profile URL was provided.
- The heavy-rain ambience is synthesized locally with the Web Audio API; no audio file or external audio service is required.
